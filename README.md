# TrayClash

**TrayClash** — легковесный и минималистичный клиент для ядра Mihomo (Clash Meta), работающий исключительно из системного трея Windows.

---

## Возможности

* **Всё в одном:** Встроенное ядро прокси и драйвер `wintun.dll` (режим TUN) упакованы прямо в исполняемый файл — никаких лишних зависимостей.
* **Поддержка кастомного ядра:** Возможность использовать собственное ядро `custom.exe` в папке с данными (`%APPDATA%\TrayClash`) — программа автоматически определит его и не будет перезаписывать.
* **Менеджер подписок:**
  * Добавление, переключение и удаление нескольких подписок.
  * Быстрое обновление активного профиля (через пункт «Обновить подписку» или повторный клик по активной подписке).
  * Автоматическое получение названия профиля из ответа сервера.
* **Выбор прокси:** Удобное переключение между серверами и группами селекторов прямо из меню трея.
* **Привязка к устройству (HWID):** Автоматическая передача HWID-идентификатора ПК при загрузке и обновлении конфигураций для работы с серверами, контролирующими лимиты устройств.
* **Импорт в один клик (Deep Links):** Поддержка протокола `tray-clash://` для быстрого добавления подписок из браузера или приложений.
* **Автозагрузка:** Запуск вместе с Windows через Планировщик задач (работает с правами администратора без всплывающих окон UAC).
* **Веб-панель:** Быстрый переход в веб-панель Zashboard для детального мониторинга трафика и соединений.
* **Портативность:** Все данные и конфигурации изолированно хранятся в `%APPDATA%\TrayClash`.

---

## Системные требования

* **ОС:** Windows 7 или новее (x86 / x64).
* **Примечание для Windows 7:** Для работы TUN-режима обязательно наличие обновления безопасности **[KB4474419](https://www.catalog.update.microsoft.com/Search.aspx?q=KB4474419)** (поддержка подписи SHA-2).

## Использование

1. Скачайте `TrayClash.exe` со страницы релизов.
2. Запустите приложение.
3. Добавьте подписку через меню **«Подписки» → «Добавить подписку...»** (или кликом по ссылке `tray-clash://`).
4. Нажмите **«Включить»** в трее.
5. Выберите нужный сервер в списке прокси.

### Кастомное ядро
Если вам требуется нестандартная или собственная сборка ядра:
1. Откройте меню **«Настройки» → «Открыть папку с данными»**.
2. Поместите туда исполняемый файл ядра с именем **`custom.exe`**.
3. Перезапустите ядро (*Выключить* → *Включить*). В меню настроек статус изменится на `✓ Ядро: custom.exe (кастомное)`.

## Deep Links (Импорт по ссылке)

Формат ссылки для мгновенного добавления профиля:
```uri
tray-clash://install-config?url=https://sub.example.com/sub?token=xxxxxxxx
```

## Сборка из исходников

Требуются [Go 1.20+](https://go.dev/) и утилита [go-winres](https://github.com/tc-hib/go-winres):

```bash
go install github.com/tc-hib/go-winres@latest
build.bat
```
Готовый исполняемый файл будет создан в папке `dist/`.
